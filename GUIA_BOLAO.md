## 🎯 Modo Clássico

Você monta a **cartela completa** da Copa: todos os 48 times 👥, classificação dos 12 grupos 🏁, terceiros colocados 🥉, chaveamento do mata-mata 🏟️ e o campeão 🏆.

### Como participar
1. Acesse o app e clique em **"📝 Palpitar"**
2. Monte seus palpites usando o **simulador interativo** 🖱️
3. Preencha os **placares dos 72 jogos da fase de grupos** ⚽
4. Defina a **classificação de cada grupo** (1º ao 4º)
5. Escolha os **4 melhores terceiros colocados**
6. Monte o **chaveamento completo** (fase_32 → oitavas → quartas → semi → final)
7. Aponte o **campeão**
8. Clique em **"💾 Salvar"** e guarde seu **código de confirmação** 🔐

### Pontuação Clássica (Modo V2)
| Acerto | Pontos |
|--------|-------|
| 🎯 Placar exato no grupo | 5 pts |
| ✅ Resultado + saldo de gols | 3 pts |
| ✅ Só o resultado (vitória/empate) | 2 pts |
| ⚽ Acertar gols de um time | 1 pt |
| 🏟️ Acertar confronto nas 16-avos | 3 pts |
| 🏟️ Acertar confronto nas oitavas | 3 pts |
| 🏟️ Acertar confronto nas quartas | 5 pts |
| 🏟️ Acertar confronto na semi | 8 pts |
| 🏟️ Acertar confronto na final | 12 pts |
| 🏆 Acertar o campeão | 20 pts |

## ⚡ Modo Jogo a Jogo

Palpite em **cada partida individualmente**, até **10 minutos antes do início** ⏰. Depois que o jogo fecha, todos os palpites são revelados 👁️.

### Como participar
1. Vá em **"⚽ Jogos de Hoje"**
2. Digite seu nome e (opcional) seu código do modo clássico para vincular 🔗
3. Para cada jogo aberto 🟢, escolha o **placar** (gols de cada time)
4. Clique em **"💾 Salvar"** — pode editar enquanto estiver aberto ✏️
5. Após o fechamento 🔒, veja os palpites de todo mundo

### Pontuação Jogo a Jogo

| Acerto | Pontos |
|--------|-------|
| 🎯 Placar exato | 5 pts |
| ✅ Resultado certo (vitória/empate) | 3 pts |
| ⚽ Acertar gols de um dos times | 1 pt |
| 📊 Acertar saldo de gols | 1 pt |

> ⚠️ **Modo "Isolated Max":** Se acertar o placar exato, leva 5 pts **sem acumular** com os outros critérios. Se não acertar o exato, soma resultado + gols + saldo.

### Ranking Combinado 🏆
O ranking **Classic + Jogo a Jogo** funde os dois modos com pesos configuráveis. Quem joga nos dois modos aparece no topo! 📈

## 🏅 Conquistas & Badges

O sistema detecta automaticamente seus feitos e exibe badges 🥇 no seu perfil:

| Badge | Requisito |
|-------|-----------|
| 🔥 **Sequência Quente** | Pontuar em 5+ jogos seguidos |
| 🦓 **Caçador de Zebras** | Acertar 3+ resultados que < 30% do grupo acertou |
| 👑 **Rei dos Exatos** | Acertar 5+ placares exatos |
| 🐐 **GOAT** | 3+ rodadas consecutivas na liderança |
| 💯 **Aproveitamento Máximo** | Acertar resultado em 80%+ dos jogos que palpitou |
| 🎰 **Sortudo** | Acertar 3+ resultados onde o favorito tinha > 70% dos votos |
| 🧹 **Não Perde um** | Palpitar em todos os jogos de uma rodada |
| 🧠 **Mestre dos Palpites** | Liderar o ranking combinado |

Os badges aparecem na página **"📊 Cartela / Perfil"** de cada participante.

## ❓ Dúvidas Frequentes

**💡 Preciso jogar nos dois modos?**
Não! Você pode jogar só o Clássico, só o Jogo a Jogo, ou ambos. O ranking combinado inclui participantes mesmo com apenas um modo.

**🔗 Como vincular meus dois modos?**
No **Jogo a Jogo**, ao identificar-se, informe o mesmo **código de confirmação** do seu palpite clássico.

**⏰ Até quando posso palpitar?**
- **Modo Clássico:** até o organizador travar (data limite)
- **Jogo a Jogo:** até **10 minutos antes** do início de cada partida

**🔄 Posso editar meu palpite?**
- **Clássico:** só pode ser enviado uma vez (rascunho → confirmado)
- **Jogo a Jogo:** pode editar **quantas vezes quiser** enquanto o jogo estiver aberto 🟢

**🐘 O que é uma "Zebra"?**
Quando um resultado é acertado por **menos de 30%** do grupo. Caçar zebras rende badges especiais!
